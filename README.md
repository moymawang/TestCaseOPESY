# PROGRAM DESCRIPTION

This program is a simple Student Record Management System written in C.

It allows the user to:
- Input multiple student records (ID, name, grade)
- Display all students
- Sort students by grade in descending order
- Search for a student by ID

# HOW TO RUN THE PROGRAM

1. Make sure you have a C compiler installed (e.g., GCC).
2. Save the file as:
   main.c
4. Open terminal/command prompt.
5. Compile the program using:
   gcc main.c -o program
6. Run the program using:
   ./program   (Linux/Mac)
   program.exe (Windows)

# ENTRY POINT

The entry point of the program is:
    main()
Located in:
    main.c

# NOTES

- Input must be entered correctly as prompted.
- The program sorts students based on grade (highest to lowest).
- Search function uses student ID.
